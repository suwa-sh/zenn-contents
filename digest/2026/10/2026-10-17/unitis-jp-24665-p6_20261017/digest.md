# ダイジェスト: タイムズカー事案から分ける本人確認書類の保管場所と消去

- 元記事: [notes/zenn/articles/unitis-jp-24665-p6_20261017.md](../../../../../articles/unitis-jp-24665-p6_20261017.md) (Zenn 下書き、未公開)
- 記事の型: ガバナンス (データの保管・消去の責任分担)
- 作成日: 2026-10-17

## ひとことで言うと

本人確認書類は「原画像」と「残す記録」で扱いを分ける。原画像は確認後に消し、消す期限は事業部門の責任者が決め、実行は別の人が点検する。委託してもリスクは一部移るだけで、監督は委託元に残る。

## 核心ポイント

1. **消すのは原画像、残すのは記録**。第4報 (2026-10-16) が「登録確認完了後は保有しない」とした対象は画像だけ。確認済みの記録、氏名・住所・生年月日、貸渡簿の運転者欄は、別の根拠で残りうる。
   - 根拠: 「確認のあと、記録は別の置き場所へ分かれる」節
2. **置き場所は「サービスに必要か」で分ける**。必要なデータは Web から届く区画に置く。保管するだけのデータはオフラインか社内の安全な区画へ移す。クラウドの透過型暗号は、読み取り権限を奪われると元の形で読まれる。
   - 根拠: 「徳丸氏が分けた保管と消去」節
3. **委託はリスクの「一部の移転」でしかない**。eKYC に預けても、個人情報保護法第25条の監督は委託元に残る。多段のサプライチェーンも狙われる。
   - 根拠: 「徳丸氏が分けた保管と消去」「移転と回避」節
4. **期限を決める人と点検する人を分ける**。事業部門の責任者が法律等の根拠で期限を決め、別の人が半年〜1年に1回点検する。現場任せだと「消すのが怖いから残す」になる。
   - 根拠: 「決定者と点検者」節
5. **「確認したら即消す」は法律の要求ではなく運営会社の選択**。第22条の消去は努力義務で、時刻を指定していない。徳丸氏も即時削除を求めていない。
   - 根拠: 「消去の条文が指定する時刻」「インタビューと、当日のルール変更」節

## 具体例: タイムズカー事案 (実例)

| 項目 | 内容 |
|---|---|
| 漏えい件数 | アカウントは約660万件。そのうち本人確認書類の画像を含むのは約160万件 (第2報・第3報) |
| 旧ルール | 現会員は会員期間中保有、退会会員は退会後7年保有 (期間は社内基準) |
| 新ルール (第4報) | 登録確認完了後、即時削除。退会後7年保有は廃止 |
| すでに持っている画像 | 申し出の有無を問わず、2026年10月末までに削除 |

## 適用と判断

自社で本人確認書類を扱う手順を作るときは、次の欄を分けて書きます。

| 欄 | 決めること |
|---|---|
| 保管場所 | 原画像の場所は Web から届く区画、保管専用の区画、委託先のどれか。検索に使う項目、暗号化する画像、鍵の置き場も書く |
| 移転と回避 | 委託するか (移転)、そもそも持たないか (回避)。委託しても監督は自社に残る |
| 決定者と点検者 | 期限と消去は事業部門の責任者。点検は別の人 (情報システム・セキュリティが候補)。監査部門には消去の判断を渡さない |
| 消すものと残すもの | 既定では原画像を消す。残す候補とその根拠は下の表を参照 |
| 完了条件 | 画像は「登録確認の完了」を消去の起点にできる。貸渡しがあれば「貸渡し終了から2年」という別の起点も置く |

残す記録と期間の根拠:

| 残す記録 | 期間の根拠 |
|---|---|
| 確認を終えたという記録 | 法令が原本を求めないときの徳丸氏の選択肢。期間の条文はない |
| 氏名・住所・生年月日 | FAQ Q8 が法人税法等に基づく7年とする |
| 貸渡簿の運転者欄 (氏名・住所・免許の種類と番号) | レンタカー通達が貸渡し終了から2年とする。事業が許可の対象だと確認できた場合に限る |

原本の保管を法令が求めない場合は、「確認済み」の記録だけを残すか、元に戻せないハッシュで照合する選択肢もあります。ただし、ハッシュの作り方によっては個人を識別できる状態が残ります。

## 限界・注意点

- **件数を取り違えない**: 約660万件はアカウント数で、免許証画像の件数ではない。
- **公式文書どうしが食い違っている**: 同日の FAQ Q8 は「運転免許情報および画像を7年保管」と書いたまま。第4報と並んで残っており、更新漏れかどうかは公表からは読めない。
- **バックアップの削除は確認できていない**: バックアップも削除対象という話は日経クロステックの伝聞で、第4報の本文に「バックアップ」の語はない。
- **法的な強さを読み違えない**: 第22条は第148条 (勧告・緊急命令) の対象に入っていない。確認後に画像を残すことを、重い義務違反と同列には扱えない。
- **7年の評価をしていない**: 徳丸氏は7年が長いか妥当かを判断していない。
